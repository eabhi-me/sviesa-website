## 🎭 Animation Flow

### On Page Load
```
1. ⚫ Black screen
   ↓ (fade in)
2. ✨ SVIESA logo appears
   ↓ (loading bar)
3. 🎬 Fade to main site
```

### On Scroll
```
Section enters viewport
    ↓
Fade in from bottom
    ↓
Stagger child elements
    ↓
Hover effects active
```

### Hover Effects
```
Card:
  Normal → Hover
  ━━━━   → ━━━━  (border color change)
  ⬜     → 🔴⬜  (accent line grows)

Button:
  [Text] → [Text]  (background shift)
  🔴     → 🔴      (slight scale up)

Image:
  □      → □      (overlay fade)
         → ━━━━  (bottom line)
```

## 🎬 Component Interaction Flow

```
User Action → Component → Visual Feedback

Scroll Down → Navbar → Becomes solid + blur
            → Sections → Fade in sequence
            → Button → Appears (scroll to top)

Hover Card  → Border → Color: gray → red
            → Line → Width: 0 → 100%
            → Content → Opacity changes

Click Link  → Smooth scroll → Target section
            → Highlight → Brief accent flash
```

## 💡 Visual Tips for Customization

### Adding Images
1. **Gallery**: Use 1200x800px images
2. **Events**: Use 800x600px images
3. **Hero**: Use 1920x1080px background

### Color Adjustments
- Keep the 60-30-10 ratio
- Use red sparingly for impact
- Maintain high contrast (7:1+)

### Spacing
- Section gaps: 5rem (80px)
- Card padding: 2rem (32px)
- Element gaps: 2rem (32px)
