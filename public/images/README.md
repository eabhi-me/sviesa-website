# Images Folder

Place your photography and media assets here:

## Recommended Structure

```
images/
├── events/
│   ├── photowalk-1.jpg
│   ├── exhibition-1.jpg
│   └── ...
├── projects/
│   ├── campus-tour.jpg
│   ├── jamming.jpg
│   └── ...
├── gallery/
│   ├── madhuram-2022.jpg
│   ├── admin-block.jpg
│   └── ...
└── logo/
    └── sviesa-logo.png
```

## Image Guidelines

- **Format**: JPG/PNG for photos, WebP for web optimization
- **Size**: Max 2MB per image (compress for web)
- **Dimensions**: 
  - Gallery images: 1200x800px (landscape) or 800x1200px (portrait)
  - Hero background: 1920x1080px
  - Thumbnails: 400x300px
- **Naming**: Use lowercase with hyphens (e.g., `photo-exhibition-2023.jpg`)

## Color Profile
- Use sRGB color space for web
- Maintain vibrant colors that work well with the dark theme
- Test images against the black background (#000000)
